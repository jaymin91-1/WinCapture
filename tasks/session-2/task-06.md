# task-06: 테두리 이동/리사이즈, 드래그 툴팁, 잠금 (F-07)
## 목표
테두리 띠 드래그로 이동, 우하단 그립 드래그로 크기 조절, 드래그 중 툴팁, 녹화 중 잠금 동작을 연결한다.
## 관련 SPEC
F-07 완료 기준 1~6, F-06-1(툴팁 오버레이), TECH-RULES 2번
## 범위
- `BorderWindow`의 `WM_NCHITTEST`에서 task-03의 히트 테스트 사용: 영역 내부 `HTTRANSPARENT`, 띠·그립은 입력 받음. 띠는 영역 바깥 8px(창은 더 넓힐 필요가 있으면 task-02/03 계산과 일관되게 처리하고 보고서에 적는다)
- 마우스 캡처로 드래그 처리, task-03 이동/리사이즈 계산 사용. 이동 커서(↔ 사방), 그립 ↘ 커서. 포커스를 가져가지 않는다
- 드래그 툴팁 창 `DragTooltipWindow : OverlayWindowBase`: `X, Y, W × H` 표시(Core 포맷 함수). 잠금 시 "녹화 중에는 영역을 변경할 수 없습니다" 표시
- 영역 변경 시 영역 상태 서비스와 설정 저장(restoreLastRegion 조건) 갱신
- 잠금 플래그를 영역 상태 서비스에 두고 세션 4에서 녹화가 켤 수 있게 인터페이스만 제공(녹화 기능 구현 금지)
## 범위 밖
- 녹화 구현, 점멸, 타이머 알약
## 완료 기준
1. [정적] 히트 테스트·이동·리사이즈·잠금 판정이 Core 호출이며 App에 별도 계산이 없다 (F-07-1~4 연결)
2. [정적] `DragTooltipWindow`가 `OverlayWindowBase`를 상속한다 (F-06-1)
3. [정적] 잠금 상태에서 드래그 시 영역 변경 없이 안내 툴팁만 표시하는 경로가 있다
4. [자동] 이 작업에서 Core를 추가·수정했다면 해당 테스트 추가. task-03 테스트 무변경
5. [CI] windows-latest build/test 성공, 새 경고 없음
6. [수동] F-07-5 (이동/↘ 커서, 드래그 툴팁), F-07-6 (잠금 툴팁)은 Windows 확인 항목. 잠금 확인용 임시 수단이 필요하면 보고서에 제안만 한다(릴리스 기능으로 넣지 않는다)
## 검증 방법
qa가 코드 읽기 + 맥 build/test + CI 확인. 기존 테스트 변경 없음을 git diff로 확인.
