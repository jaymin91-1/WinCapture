# task-02: Core 좌표 변환·영역 정규화·테두리 사각형 (F-04, F-05, F-06 계산부)
## 목표
물리 픽셀 기준 사각형 모델, DIP↔물리 변환, 드래그 정규화와 최소 크기 판정, 테두리 창 사각형 계산을 Core에 구현한다.
## 관련 SPEC
F-04 완료 기준 3~5, F-05 완료 기준 1~4, F-06 완료 기준 3, TECH-RULES 4~5번
## 범위
- Core: 정수 `Rect`/`Point`/`Size` 값 형식(WPF·System.Drawing 형식 사용 금지)
- DIP↔물리 변환 유틸(배율 입력, 반올림은 `MidpointRounding.AwayFromZero`, 역변환 포함). WPF DIP 변환은 이 유틸 한 곳에서만 하도록 설계
- 드래그 시작·끝점 → 정규화 사각형, 최소 32px 판정(W 또는 H < 32면 무효)
- 테두리 바깥 사각형 계산(영역 + 두께): 영역 안쪽 픽셀을 덮지 않음
- 마지막 영역 복원: `AppSettings.lastRegion`과 `Rect` 간 변환, `restoreLastRegion` 옵션이 켜진 경우에만 복원값 제공, 꺼져 있거나 크기 0이면 없음. 저장된 영역이 가상 화면과 겹치지 않거나 벗어나면 가상 화면 안으로 보정하는 순수 함수 제공(보정 규칙은 보고서에 적는다)
- App 매니페스트의 Per-Monitor V2 선언 여부 확인(이미 있으면 변경 없음)
## 범위 밖
- 실제 창, 모니터 열거, 설정 저장 호출(task-05)
- 히트 테스트, 이동/리사이즈 계산(task-03)
## 완료 기준
1. [자동] (500,400)→(100,100) 정규화 시 X=100, Y=100, W=400, H=300. 네 방향 모두 테스트 (F-04-3)
2. [자동] W 또는 H가 32 미만인 드래그는 무효, 32×32는 유효 (F-04-4)
3. [자동] restoreLastRegion=true일 때 lastRegion이 `Rect`로 복원되고 설정 저장 후 다시 읽어도 같다. false이면 복원되지 않는다 (F-04-5)
4. [자동] 150%에서 DIP (100,100,400,300) → 물리 (150,150,600,450), 역변환 성립 (F-05-1)
5. [자동] 125%에서 DIP (101,101,401,301) → 물리 (126,126,501,376) (F-05-2)
6. [자동] 100%에서 DIP (-1920,0,800,600) → 물리 (-1920,0,800,600) (F-05-3)
7. [정적] 매니페스트에 Per-Monitor V2 선언이 있다(파일:줄 근거) (F-05-4)
8. [자동] 영역 (100,100,400,300), 두께 2 → 테두리 창 사각형 (98,98,404,304), 영역 내부 픽셀과 겹치지 않음 (F-06-3)
9. [정적] Core가 WPF/Win32/System.Drawing을 참조하지 않는다
10. [CI] windows-latest build/test 성공
11. [수동] F-05-5는 세션 종료 시 사용자 확인(100%/150% 모니터에서 테두리 픽셀 일치)
