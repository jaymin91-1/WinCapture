# change-20261127-06: 컨트롤 바 재배치와 작업표시줄 아이콘
## 목표
컨트롤 바를 SPEC 4장 "컨트롤 바" 4단 배치로 다시 만들고, Windows 작업표시줄에 앱 아이콘이 실제로 나타나지 않는 원인을 규명해 고친다. 20261127-05(영역 상태 이벤트·`Clear()`)가 통과한 뒤 그 위에서 작업한다.

## 관련 SPEC
- 4장 "컨트롤 바", "앱 아이콘"(작업표시줄 표시 필수), "영역 상태", 3장 팔레트, 7장 `captureMode`
- 이전 작업: 20261127-04(컨트롤 바·아이콘 1차 구현, 사용자 확인에서 작업표시줄 아이콘 미표시, 레이아웃 불만)

## 범위
1. 컨트롤 바 재배치 (위→아래 4단)
   1. 상태 줄: `지정 영역` / `전체 화면` + 좌표 `X, Y, W × H`(물리 픽셀). 테두리 숨김 중(ToggleBorder로 숨김)이면 그 사실을 짧게 덧붙인다(전체 화면은 원래 테두리가 없으므로 "숨김" 표시 대상이 아니다. 지정 영역일 때만). 05의 영역 상태 변경 이벤트로 즉시 갱신. 표시 문자열 생성은 Core의 순수 함수(상태·사각형·테두리 숨김 여부 → 문자열)로 두어 테스트한다.
   2. 모드 선택: [사진] [동영상] [GIF] 단일 선택(기존 captureMode 저장·복원 유지).
   3. 버튼 5개: [영역 지정] [영역 해제] [캡처] [설정] [창 표시·숨김]. [영역 해제]는 05의 `Clear()`(ClearRegion 단축키와 같은 경로). [캡처]의 미구현 모드 비활성+툴팁은 04 동작 유지.
   4. 단축키 안내: 현재 설정된 단축키를 작은 글씨 레이블로 표시(예: `영역 지정 Ctrl+Alt+R`). 설정에서 단축키가 바뀌면 갱신. 표시 문자열 생성은 Core 순수 함수로 두어 테스트한다.
   - 창 크기는 작게 고정, 리사이즈·최대화 불가(`ResizeMode=CanMinimize` 또는 `NoResize` 등, 최대화 버튼 없음). 내용에 맞춘 고정 크기(DPI 배율에서 잘리지 않도록 SizeToContent 후 고정 권장). 3장 팔레트와 01 스타일 리소스(라이트/다크). 기존 동작(X=숨김, 시작 시 표시, 트레이 왼쪽 클릭, 창 표시·숨김 단일 경로, autoHideAppWindow)은 그대로 유지한다.
2. 작업표시줄 아이콘 미표시 원인 규명과 수정
   - 04에서 exe `ApplicationIcon`, 창 `Icon`을 지정했는데도 작업표시줄에 아이콘이 안 보였다. 추측하지 말고 코드·빌드 설정에서 원인을 찾아 보고서에 "원인"으로 적는다. 최소한 다음을 확인한다: (a) .ico의 빌드 액션(Resource 등)과 `Window.Icon`의 pack URI가 올바른지, (b) 창이 WPF-UI `FluentWindow`/`TitleBar` 계열이면 `Window.Icon` 설정만으로 작업표시줄 아이콘이 나오는지 또는 `TitleBar.Icon`이 따로 필요한지, 창 핸들에 `WM_SETICON`(ICON_BIG/ICON_SMALL)을 보내야 하는지, (c) `ShowInTaskbar`·창 스타일(WS_EX_TOOLWINDOW 등)이 작업표시줄 버튼을 막지 않는지, (d) .ico가 실제로 유효한 다중 크기 ICO인지(헤더 검증, 16/24/32/48/256 포함 여부), 작업표시줄에 쓰이는 크기(24/32/48 등)가 들어 있는지, (e) 아이콘 로딩 중 예외가 삼켜지는지, (f) exe 임베드 아이콘 자체가 비어 있지 않은지(csproj `ApplicationIcon` 경로).
   - 맥에서 확인 가능한 정적 근거(파일:줄, ICO 헤더 덤프, 빌드 산출물의 리소스/매니페스트 확인 등)를 보고서에 붙인다. 원인이 여러 개면 모두 수정한다.
   - 수정 방식은 coder 판단. 단 새 NuGet 금지. 필요하면 .ico 재생성(생성 스크립트 갱신, 원본 직접 생성 유지)을 허용한다.
   - 추가 안전장치로 컨트롤 바·설정 창이 Loaded/SourceInitialized에서 코드로 아이콘을 명시 설정하는 방법(예: `Icon = BitmapFrame.Create(pack URI)`, 필요 시 WM_SETICON)을 쓸 수 있다. 실패 시 로그를 남긴다.
3. 기존 오버레이 창은 변경하지 않는다.

## 범위 밖
- 동영상/GIF 녹화 기능 자체, 트레이 메뉴 구성 변경, 설정 창 탭 변경
- 05에서 끝낸 영역 상태 로직 변경(필요한 읽기 API 추가 정도는 허용)
- SPEC/TECH-RULES/SESSIONS 수정, 새 NuGet 패키지

## 완료 기준
1. [CI] 솔루션 build와 test가 windows-latest에서 성공하고, 맥 `dotnet test tests/WinCapture.Core.Tests`와 `dotnet build WinCapture.sln`이 통과한다. 기존 테스트 삭제·skip·기대값 변경 없음, 새 경고 없음.
2. [자동] 상태 줄 문자열 순수 함수 테스트: 전체 화면 (0,0,1920,1080) → `전체 화면` + `0, 0, 1920 × 1080` 포함. 지정 영역 (100,100,400,300) → `지정 영역` + `100, 100, 400 × 300` 포함. 지정 영역 + 테두리 숨김이면 "숨김" 표시가 추가되고, 전체 화면에서는 테두리 숨김 여부와 무관하게 추가되지 않는다. 음수 좌표 (-1920,0,1920,1080) → `-1920, 0, 1920 × 1080`.
3. [자동] 단축키 안내 문자열 순수 함수 테스트: 기본 설정에서 `영역 지정 Ctrl+Alt+R`, `스크린샷 Ctrl+Alt+S` 등이 생성되고, 설정의 단축키를 바꾸면 결과가 바뀐다. 빈 문자열/미설정 단축키는 "없음" 등 일관된 표기(보고서에 규칙 명시).
4. [정적] 컨트롤 바 XAML이 SPEC 4단 배치(상태 줄 → 모드 3개 → 버튼 5개 → 단축키 레이블)를 위→아래 순서로 갖는다. 버튼 5개의 이름·순서가 SPEC과 일치한다. (파일:줄 기록)
5. [정적] 크기 고정·리사이즈 불가·최대화 불가가 XAML/코드로 설정되어 있다(`ResizeMode`, 최대화 버튼 제거 등). 닫기(X)=Hide, 시작 시 표시, ShowInTaskbar=true가 유지된다. `OverlayWindowBase`를 상속하지 않는다. (파일:줄 기록)
6. [정적] 상태 줄이 05의 영역 상태 변경 이벤트를 구독해 갱신하고 창 닫힘 시 구독이 해제된다(또는 수명이 앱과 같음을 보고서에 명시). 단축키 레이블이 설정 변경 시 갱신된다. [영역 해제]가 `Clear()`를 호출한다. (파일:줄 기록)
7. [정적] 작업표시줄 아이콘 미표시의 **원인**이 보고서에 코드 근거와 함께 적혀 있고, 그 원인에 대응하는 수정이 코드에 있다. 위 확인 항목(a)~(f)별 결과가 보고서에 있다. ICO 파일이 유효한 다중 크기이며 작업표시줄용 크기를 포함한다는 근거(헤더 덤프 등)가 있다. 컨트롤 바·설정 창·exe 모두 아이콘이 지정되어 있다. (파일:줄 기록)
8. [정적] 새 NuGet 없음, Core에 WPF 참조 없음, `WH_KEYBOARD_LL` 미사용, 빌드 산출물·비밀 값 미커밋. 기존 오버레이 창은 모두 여전히 `OverlayWindowBase`를 상속한다. 이전 동작(창 표시·숨김 단일 경로, 트레이 왼쪽 클릭, autoHide, 모드 저장·복원)의 코드가 유지된다.
9. [수동] Windows 작업표시줄에 앱 아이콘이 나타난다(컨트롤 바 표시 중). 설정 창·컨트롤 바 제목줄과 exe 파일에도 같은 아이콘이 보인다.
10. [수동] 컨트롤 바가 위→아래 4단(상태 / 모드 / 버튼 5개 / 단축키 작은 글씨)으로 보이고, 작고, 가장자리를 끌어도 크기가 바뀌지 않으며 최대화가 되지 않는다. 100%/150% 배율에서 내용이 잘리지 않고 라이트/다크 설정을 따른다.
11. [수동] 상태 줄이 시작 시 `전체 화면`과 좌표를 보여 주고, 영역을 지정하면 즉시 `지정 영역`과 좌표로 바뀐다. 테두리 이동·리사이즈 중/후 좌표가 갱신된다. ToggleBorder로 숨기면 "숨김" 표시가 붙는다.
12. [수동] [영역 해제] 버튼과 ClearRegion 단축키가 같은 결과(전체 화면 상태, 테두리 없음)를 낸다. [영역 지정], [캡처](사진), [설정], [창 표시·숨김]이 이전처럼 동작한다.
13. [수동] 설정 창에서 단축키를 바꾸면 컨트롤 바 하단 단축키 레이블이 바뀐다.
