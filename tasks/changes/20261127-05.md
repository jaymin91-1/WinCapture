# change-20261127-05: 영역 상태 모델 (지정 영역 / 전체 화면)
## 목표
SPEC "영역 상태"를 구현한다. 앱 시작 시와 ClearRegion 후에는 마우스 커서가 있는 모니터 한 대의 전체 사각형(전체 화면 상태)이 되고, 영역은 저장·복원하지 않는다. 20261127-06(컨트롤 바 재배치)보다 먼저 진행한다.

## 관련 SPEC
- 5장 F-04 기준 2~5, "영역 상태" 절, F-05(물리 픽셀), F-06 기준 6, F-02 기준 3, 7장(`restoreLastRegion`/`lastRegion` 삭제)
- 4장 "컨트롤 바"의 [영역 해제]는 06에서 UI를 붙인다. 이번 작업은 ClearRegion 단축키 경로까지.

## 범위
1. Core: 영역 상태 모델
   - 상태 두 가지(지정 영역 / 전체 화면)를 구분할 수 있는 모델. 상태 변경 시 이벤트(06의 상태 줄이 구독한다). 현재 상태, 사각형(물리 픽셀)을 읽을 수 있어야 한다.
   - 기존 `RegionState`/`RegionCoordinator`를 확장·정리하는 것은 자유. 단 Core는 WPF/Win32/System.Drawing 비참조.
2. Core: 커서 모니터 선택 순수 함수
   - 모니터 목록(물리 픽셀 사각형 목록)과 커서 좌표(물리 픽셀)를 인자로 받아, 커서가 속한 모니터의 전체 사각형을 반환한다. 음수 좌표(주 모니터 왼쪽/위 모니터) 지원, 경계는 `[X, X+W)`, `[Y, Y+H)`.
   - 어떤 모니터에도 속하지 않거나 목록이 비면 대체 동작이 필요하다. SPEC에 없으므로 coder는 임의로 정하지 말고 보고서에 "필요한 결정"으로 적되, 진행을 위해 임시로 "목록의 첫 모니터(주 모니터), 목록이 비면 전체 화면 없음(null)"로 구현하고 그 사실을 명시한다. 진행자가 사용자에게 확인한다.
3. Core: 시작·해제 동작
   - 시작 시 전체 화면 상태(모니터 목록·커서 좌표는 주입). `Clear()`(ClearRegion)는 지정 영역을 버리고 그 시점의 커서 모니터 전체 화면 상태로 바꾼다. 이미 전체 화면이어도 커서 모니터를 다시 고른다.
   - 영역 지정(드래그 확정)이 유효하면 지정 영역 상태가 된다. 32px 미만/Esc 취소는 현재 상태를 유지한다(전체 화면이면 전체 화면 유지).
4. Core: 저장/복원 제거
   - `AppSettings`에서 `restoreLastRegion`, `lastRegion`(및 `RegionSettings`가 다른 곳에서 안 쓰이면 함께)을 삭제한다. 저장 시 JSON에 이 키가 나오지 않는다. 기존 파일에 있어도 읽기에 실패하지 않고 무시한다. 영역 저장 코드(`SaveLastRegion` 등)와 복원 코드(`RegionMath`의 복원 계산 등)를 삭제한다.
   - 기존 복원 관련 테스트(`RegionCoordinatorTests`의 restore/lastRegion 관련, `Clear_RemovesRegionAndEmptiesSavedLastRegion_ThenNoRestore` 등)는 SPEC 변경(F-04-5)으로 전제가 사라졌으므로 새 기준 테스트로 **교체**하는 것을 허용한다. 이것은 SESSIONS.md 공통 기준 5의 "테스트 삭제·기대값 변경 금지"의 예외로, SPEC이 명시적으로 교체를 지시했기 때문이다. 단 다음을 지킨다.
     - 보고서에 "교체한 테스트 목록"(기존 이름, 교체한 이유, 대체 테스트 이름)을 표로 적는다. 복원과 무관한 테스트(드래그 정규화, 32px, DPI, 테두리 계산, 단축키 등)는 건드리지 않는다.
     - 그 외 테스트의 삭제·skip·기대값 변경은 금지.
5. 테두리: 전체 화면 상태에서는 테두리를 표시하지 않고 이동·리사이즈 대상도 아니다. 지정 영역에서만 표시한다(ToggleBorder 상태와는 독립: 전체 화면이면 ToggleBorder가 켜져 있어도 숨김). 이 판정은 Core의 순수 로직(`ShouldShowBorder` 등)에 둔다.
6. App/Native 연결
   - 모니터 열거와 커서 좌표 조회(Native, 물리 픽셀. 예: EnumDisplayMonitors/GetCursorPos 또는 동등한 방법, Per-Monitor V2 환경에서 물리 좌표임을 보장)를 구현하고 Core 함수에 주입한다.
   - 앱 시작 시 전체 화면 상태로 초기화한다. 시작 시 저장된 영역을 읽는 코드를 제거한다.
   - 단축키 ClearRegion은 `Clear()`를 호출해 전체 화면 상태로 전환한다(테두리 사라짐).
   - 스크린샷은 현재 상태의 사각형(지정 영역이면 그 영역, 전체 화면이면 그 모니터 전체)을 캡처한다. 기존 "영역 없음이면 안내" 분기가 있으면 전체 화면 상태에서는 더 이상 해당 없음으로 정리한다.

## 완료 기준
1. [CI] 솔루션 build와 test가 windows-latest에서 성공하고, 맥 `dotnet test tests/WinCapture.Core.Tests`와 `dotnet build WinCapture.sln`이 통과한다. 새 경고 없음.
2. [자동] 커서 모니터 선택: 모니터 [(0,0,1920,1080), (1920,0,2560,1440)]에서 커서 (100,100) → (0,0,1920,1080), 커서 (3000,500) → (1920,0,2560,1440), 경계 커서 (1920,0)은 두 번째 모니터, (1919,1079)는 첫 번째. 음수 좌표 모니터 [(-1920,0,1920,1080),(0,0,2560,1440)]에서 커서 (-1,10) → 첫 번째, (0,10) → 두 번째. 대응 xUnit 테스트가 있다.
3. [자동] (F-04-5) 새로 만든 영역 상태 객체는 전체 화면 상태이며, 사각형은 주입된 커서 모니터의 전체 사각형이다. 설정에 영역 관련 값이 있어도 사용하지 않는다.
4. [자동] 지정 영역 상태에서 `Clear()` 후 상태는 전체 화면이고 사각형은 그 시점 커서 모니터의 전체 사각형이다(커서가 다른 모니터로 옮겨진 뒤 Clear하면 새 모니터). 상태 변경 이벤트가 발생한다.
5. [자동] 유효한 드래그 확정 시 지정 영역 상태가 되고, 예: (500,400)→(100,100)이면 (100,100,400,300). 32px 미만 드래그/취소는 이전 상태(지정 영역이면 그 영역, 전체 화면이면 전체 화면)를 유지한다.
6. [자동] 전체 화면 상태에서 테두리 표시 여부가 false이고(ToggleBorder가 켜져 있어도), 지정 영역 + 테두리 켜짐에서만 true이다.
7. [자동] 설정 저장 JSON에 `restoreLastRegion`/`lastRegion` 키가 없다. 이 키가 들어 있는 기존 JSON을 읽어도 예외 없이 나머지 값이 로드된다(F-02-3). 왕복 동일 테스트(F-02-1)는 유지된다.
8. [정적] Core가 WPF/Win32/System.Drawing을 참조하지 않는다. 모니터 열거·커서 조회는 Native/App에 있고 Core 순수 함수에 주입된다. `WH_KEYBOARD_LL` 미사용. (파일:줄 기록)
9. [정적] 영역 저장·복원 코드가 전부 제거되었다(`grep -ri "lastRegion\|restoreLastRegion"`이 코드·테스트에서 삭제 테스트 설명/마이그레이션 테스트 외에 남지 않음). 시작 시 전체 화면 초기화, ClearRegion 단축키 → `Clear()` 연결, 스크린샷이 현재 상태 사각형을 쓰는 지점을 파일:줄로 기록한다.
10. [정적] 보고서에 "교체한 테스트 목록"이 있고, git diff상 그 외 기존 테스트의 삭제·skip·기대값 변경이 없다. 기존 오버레이 창은 모두 여전히 `OverlayWindowBase`를 상속한다.
11. [정적] 새 NuGet 없음, 빌드 산출물·비밀 값 미커밋.
12. [수동] 앱을 시작하면 영역이 전체 화면 상태(테두리 없음)이고, 스크린샷이 커서가 있던 모니터 전체를 저장한다. (멀티 모니터면 커서 모니터 기준)
13. [수동] 영역을 지정하면 빨간 테두리가 뜨고, 앱을 종료·재시작하면 영역이 초기화(전체 화면, 테두리 없음)된다.
14. [수동] ClearRegion 단축키(기본 Ctrl+Alt+X)로 테두리가 사라지고 전체 화면 상태가 된다. 커서를 다른 모니터에 둔 뒤 누르면 그 모니터가 대상이 된다. 전체 화면 상태에서 ToggleBorder를 눌러도 테두리가 나타나지 않는다.
