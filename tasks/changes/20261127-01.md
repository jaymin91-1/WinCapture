# change-20261127-01: 설정 창/트레이 메뉴를 흰색/파랑 목업 스타일로 변경
## 목표
세션 1에서 만든 설정 창 껍데기와 트레이 메뉴의 외형을, 사용자가 승인한 흰색/파랑 목업(docs/design/mockup/)에 가깝게 WPF로 구현한다. 목업은 HTML이므로 "근사" 구현이 목표다. 다음 세션에서 재사용할 공통 스타일 리소스 사전도 만든다.

## 관련 SPEC
- SPEC 3장 디자인 원칙 (색 값, 카드 12px/컨트롤 8px, 굵은 Segoe UI, 키캡, Mica 사용 안 함, 시스템 라이트/다크 추종, 앱 고유 파랑)
- SPEC 4장 (탭 순서, 트레이 메뉴 항목 순서), SPEC 7장 (기본 단축키 값)
- TECH-RULES.md UI 줄 (WPF-UI 사용, Mica 없음)
- 목업: docs/design/mockup/Main.dc.html(라이트 일반 탭), Dark.dc.html(다크 단축키 탭), Tray.dc.html(트레이 라이트/다크)

## 범위
- 색 리소스 사전 신설 (예: src/WinCapture.App/Themes/Colors.Light.xaml, Colors.Dark.xaml 및 공용 Styles.xaml). SPEC 3장의 라이트/다크 색 값을 그대로 브러시 키로 정의한다(창 바탕, 카드, 사이드바/제목 표시줄, 테두리, 본문, 보조, 강조, 선택 탭 바탕/글자, 경고). 시스템 라이트/다크 전환 시 리소스가 바뀐다(시스템 테마 자동 추종). 강조색은 시스템 강조색이 아니라 앱 고유 파랑이다.
- 공통 스타일 정의(내용 없이 스타일만): 카드(모서리 12px), 설정 행(제목/설명/오른쪽 컨트롤 영역), 토글 스위치, 키캡, 컨트롤 기본(모서리 8px), 페이지 제목(굵은 Segoe UI).
- 설정 창: Mica 제거(WindowBackdropType 단색), 창 바탕/제목 표시줄/사이드바/선택 탭 표시를 목업대로. 탭 6개와 순서(일반/단축키/캡처/녹화/FFmpeg/정보)는 유지. 각 탭 페이지는 빈 껍데기 그대로 두되 페이지 제목과 배경은 새 스타일을 따른다.
- 트레이 메뉴: ContextMenu/MenuItem 스타일(배경, 테두리, 모서리, 호버, 구분선)을 목업대로 적용하고 항목 오른쪽에 단축키를 표시한다. 단축키 문구는 SPEC 7장 기본값: 영역 지정 Ctrl+Alt+R, 스크린샷 Ctrl+Alt+S, 동영상 녹화 Ctrl+Alt+V, GIF 녹화 Ctrl+Alt+G, 창 표시/숨김 Ctrl+Alt+W. 저장 폴더 열기/설정/종료는 단축키 표시 없음. 항목 순서와 기존 동작(설정, 종료)은 그대로.
- README.md 11행의 "Windows 11 Fluent 디자인(Mica, ...)" 문구를 새 스타일(심플한 흰색/파랑, 시스템 라이트/다크 추종)로 갱신.

## 범위 밖
- 탭 내부의 실제 설정 컨트롤(저장 폴더, 단축키 편집 등) 구현 (세션 6)
- 트레이 메뉴 항목의 실제 동작 연결 (기존처럼 비활성 유지)
- 새 라이브러리 추가, SPEC/TECH-RULES/SESSIONS 수정, 캡처 테두리 등 오버레이 색 변경
- 설정 값(settings.json) 변경, 다크/라이트 수동 전환 옵션

## 완료 기준
1. [CI] 솔루션 build와 test가 windows-latest에서 성공하고, 맥 `dotnet test tests/WinCapture.Core.Tests`가 기존 테스트 삭제·skip 없이 통과한다.
2. [정적] 리소스 사전의 라이트 색이 SPEC 3장과 정확히 일치한다: 창 바탕 #F2F4F6, 카드/사이드바/제목 표시줄 #FFFFFF, 테두리 #E5E8EB, 본문 #191F28, 보조 #6B7684, 강조 #2F7CF6, 선택 탭 바탕 #E8F3FF, 선택 탭 글자 #1B64DA. (파일:줄을 리뷰에 기록)
3. [정적] 다크 색이 SPEC 3장과 정확히 일치한다: 창 바탕 #17171C, 사이드바/제목 표시줄 #101013, 카드 #202027, 테두리 #2C2C35, 본문 #F9FAFB, 보조 #A0A7B1, 강조 #4D8EF7, 경고 #FF7A85.
4. [정적] SettingsWindow.xaml에 Mica 백드롭이 없고(WindowBackdropType="Mica" 제거), 시스템 강조색(SystemAccentColor 등)에 의존하지 않으며, 시스템 라이트/다크 추종 코드가 존재한다.
5. [정적] 공통 스타일(카드 CornerRadius=12, 컨트롤 CornerRadius=8, 토글, 키캡, 설정 행, 페이지 제목)이 리소스 사전에 키로 정의되어 있고, 색은 하드코딩이 아니라 브러시 리소스를 참조한다.
6. [정적] 트레이 메뉴 항목 순서가 SPEC 4장과 같고, 단축키 표시 문구가 SPEC 7장 기본값과 일치한다. 탭 6개와 순서가 유지된다.
7. [정적] README.md에 "Mica" 문구가 없고 새 스타일이 반영되어 있다. Core가 WPF 참조를 추가하지 않았고(TECH-RULES), 새 NuGet 패키지가 없다.
8. [수동] Windows 라이트 모드에서 설정 창이 Main.dc.html 목업과 비슷하다(회색 바탕, 흰 사이드바/제목 표시줄, 선택 탭이 연파랑 바탕+파랑 글자, 모서리 둥근 느낌).
9. [수동] Windows 다크 모드에서 설정 창이 Dark.dc.html 목업과 비슷하다(어두운 바탕, 사이드바 더 어두움, 강조 파랑). 테마를 바꾸면 앱 재시작 없이 또는 재시작 후 반영된다.
10. [수동] 트레이 아이콘 클릭 시 메뉴가 Tray.dc.html(라이트/다크)과 비슷하고, 항목 오른쪽에 단축키가 보이며, 설정/종료가 기존처럼 동작한다.
