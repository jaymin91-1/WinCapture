## 내린 판단과 이유
- 모니터 대체 동작은 임시안: 커서가 어느 모니터에도 없으면 주 모니터 → 없으면 목록 첫 모니터 → 모두 없으면 null(이때는 지정 영역만 해제하고 전체 화면 사각형은 비어 있음, `CaptureRect`=null). `MonitorSelector.cs`에 임시 표기함. **진행자가 사용자 확인 필요.**
- 목록이 비고 주 모니터가 있으면 주 모니터를 쓴다(요청의 "목록이 비면 주 모니터").
- `ClampToVirtualScreen`은 복원 전용이었으나 복원과 무관한 테스트가 있어 유지(미사용 코드).
- `Clear()`는 녹화 잠금 중에도 막지 않음(기존 동작 유지).
