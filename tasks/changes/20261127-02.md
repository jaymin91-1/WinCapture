# change-20261127-02: 트레이 아이콘과 설정 창 탭 아이콘 교체
## 목표
트레이 아이콘을 "강조 파랑 둥근 사각형 + 흰 점"으로, 설정 창 탭 아이콘 6개를 목업의 얇은 선 아이콘으로 바꾼다. 직전 수정 20261127-01(통과)의 리소스/스타일 위에 작업한다.

## 관련 SPEC
- SPEC 3장 디자인 원칙의 트레이 아이콘, 설정 창 탭 아이콘 규칙 (커밋 97f01ad). 라이트/다크 색 값, 시스템 테마 추종 규칙
- 목업: docs/design/mockup/Main.dc.html 의 nav SVG (viewBox 24, 18px, stroke-width 1.6, stroke=currentColor), 같은 파일 21행 앱 로고(둥근 사각형 + 원)
- TECH-RULES.md: 트레이는 H.NotifyIcon.Wpf, 새 패키지 금지

## 범위
- 트레이 아이콘 원본(App.xaml의 TrayIconImage DrawingImage, 현재는 어두운 사각형+빨강 점+모서리 괄호)을 교체: 배경 #2F7CF6 둥근 사각형, 중앙에 흰색(#FFFFFF) 원. 앱이 직접 그린 벡터 원본이며 외부 이미지/타사 로고를 쓰지 않는다. 트레이는 라이트/다크 모두 파랑 배경이므로 테마 분기 없이 하나로 둔다.
- 설정 창 탭 6개의 아이콘(SettingsWindow.xaml의 SymbolIcon)을 목업 nav SVG와 같은 모양의 선 아이콘으로 교체: 일반=톱니(원+8방향 선), 단축키=키보드, 캡처=모서리 괄호, 녹화=비디오 카메라, FFmpeg=렌치, 정보=원 안의 i. SVG path 데이터를 WPF Geometry(Path Data)로 옮기고, 24x24 좌표를 18px로 표시(Viewbox 등), 선 두께는 24 좌표 기준 1.6(18px 표시 시 약 1.2px가 되므로 "약 1.6" 시각 두께가 되도록 표시 크기 대비 조정 가능), 선 끝/모서리 둥글게(round cap/join)로 목업과 맞춘다. 채움 없음(Fill 없음).
- 아이콘 선 색은 하드코딩하지 않고 글자색을 따른다: 탭 항목의 Foreground(선택 시 선택 탭 글자색, 평소 본문/보조색)를 상속하는 방식으로, 20261127-01의 브러시 리소스와 AppNavigationItemStyle 안에서 처리. 라이트/다크 전환 시 아이콘 색이 함께 바뀐다.
- 아이콘 geometry는 재사용 가능한 리소스(예: Themes/Icons.xaml 또는 Styles.xaml 안 Geometry 키)로 정의한다.
- 탭 6개의 개수와 순서, 페이지 연결, 트레이 메뉴 항목/동작은 그대로 둔다.

## 범위 밖
- 20261127-01 리뷰에서 남은 Windows 확인 항목(설정 창 전체 외형, 다크 전환, 트레이 메뉴 외형 등)의 재확인
- 녹화 중 트레이 아이콘 상태 변경(세션 해당 작업에서 구현)
- 새 NuGet 패키지, 외부 아이콘/이미지 파일(PNG/ICO) 추가, SPEC/TECH-RULES/SESSIONS 수정
- 탭 내부 컨트롤, 앱 exe 아이콘(ApplicationIcon) 지정

## 완료 기준
1. [CI] 솔루션 build와 test가 windows-latest에서 성공하고, 맥 `dotnet test tests/WinCapture.Core.Tests`가 기존 테스트 삭제·skip 없이 통과한다.
2. [정적] TrayIconImage가 #2F7CF6 둥근 사각형과 흰(#FFFFFF) 원으로만 구성되고, 이전의 어두운 배경/빨강 점/모서리 괄호가 제거되었다. 외부 이미지 파일 참조가 없다. (파일:줄 기록)
3. [정적] 탭 아이콘 6개가 SymbolIcon이 아닌 Path 기반 선 아이콘이며, 각 geometry가 목업 Main.dc.html 33~55행의 해당 SVG path와 일치한다(일반/단축키/캡처/녹화/FFmpeg/정보 순). Fill 없음, 선 두께 약 1.6(24 좌표 기준) 또는 18px 표시 기준 시각 두께가 이에 상응, round cap/join. (파일:줄 기록)
4. [정적] 아이콘 Stroke가 하드코딩 색이 아니라 탭 항목 Foreground를 따른다(RelativeSource/TemplateBinding/스타일 바인딩 등). 라이트/다크 어느 쪽에서도 고정 색이 없다. (파일:줄 기록)
5. [정적] 탭 6개와 순서, 트레이 메뉴 항목 순서와 동작이 변경 전과 같다. 새 NuGet 패키지 추가가 없고 Core에 WPF 참조가 없으며, 바이너리 이미지/ICO 파일이 커밋되지 않았다.
6. [수동] Windows 트레이 영역(라이트/다크 작업 표시줄 모두)에서 파랑 둥근 사각형 안 흰 점 아이콘이 보인다.
7. [수동] 설정 창 사이드바 6개 탭에 얇은 선 아이콘이 목업과 비슷하게 보이고(일반=톱니, 단축키=키보드, 캡처=모서리 괄호, 녹화=카메라, FFmpeg=렌치, 정보=원 안의 i), 선택 탭에서는 파랑 글자색, 선택 안 된 탭에서는 평소 글자색으로 아이콘이 같은 색을 따른다.
8. [수동] 시스템 라이트/다크 전환 후(재시작 허용) 탭 아이콘 색이 글자색과 함께 바뀌어 어느 쪽에서도 또렷하게 보인다.
