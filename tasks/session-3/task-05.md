# task-05: 단축키 등록 실패 알림을 토스트로 전환
## 목표
세션 2에서 트레이 풍선으로 임시 처리한 단축키 등록 실패 알림을 task-03의 토스트로 바꾼다. 작은 항목이다.
## 관련 SPEC
F-03-5(등록 실패 토스트), 4장 토스트 알림, TECH-RULES 제약 7(등록 실패 시 사용자에게 알리고 설정에서 변경하도록 안내)
## 범위
- `HotkeyService`의 실패 알림 콜백을 `IToastService` 경고 토스트로 교체한다(`App.xaml.cs:104`의 `_trayIcon?.ShowNotification` 제거). 문구는 기존 풍선 문구를 유지하거나 같은 의미로 하되 "설정 › 단축키 탭에서 변경" 안내를 포함한다
- 여러 단축키가 동시에 실패하면 토스트가 폭주하지 않도록 한 번에 한 개로 묶거나 task-03의 쌓기에 맡긴다(구현 방식은 coder 선택, 보고서에 적는다)
- `Reapply()`(설정 변경 후 재등록) 경로에서도 같은 토스트가 나온다. 단축키 팝업의 `사용 중인 조합` 표시는 그대로 유지
- 풍선 알림 코드가 더 이상 쓰이지 않으면 제거한다. 트레이 아이콘 자체는 건드리지 않는다
## 범위 밖
- 단축키 편집 UI(세션 6), 토스트 창 자체 수정(task-03)
## 완료 기준
1. [자동] 실패 알림 문구/묶기 규칙을 Core로 뺀 경우 그 로직의 단위 테스트가 있다(예: 실패 동작 목록 → 토스트 본문). Core로 빼지 않았다면 이 기준은 [정적]으로 갈음하고 보고서에 이유를 적는다
2. [정적] 실패 알림이 `IToastService`를 거치고 `ShowNotification`(풍선) 호출이 남아 있지 않다 (파일:줄)
3. [정적] 알림에 "설정 › 단축키" 변경 안내가 포함된다
4. [정적] 기존 HotkeyService의 `Statuses`와 단축키 팝업 표시 동작이 변경되지 않았다(기존 테스트 유지)
5. [CI] windows-latest build/test 성공, 새 경고 없음
6. [수동] F-03-5: 다른 앱이 쓰는 조합을 가진 상태로 실행하면 우하단 토스트가 뜨고 팝업에 빨간 테두리·`사용 중인 조합`이 보인다 → Windows 확인 항목
## 검증 방법
qa가 코드 읽기 + 맥 build/test + CI 확인. grep으로 `ShowNotification` 잔존 여부 확인.
