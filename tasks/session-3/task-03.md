# task-03: 토스트 알림 창
## 목표
저장 완료·오류·경고를 보여 주는 토스트 알림을 만든다. 새 라이브러리 없이 WPF 창으로 구현한다.
## 관련 SPEC
4장 "토스트 알림: 저장 완료, 변환 진행/완료, 오류", F-09-5(토스트 클릭 → 탐색기에서 파일 선택), F-03-5(등록 실패 토스트), F-06-1·2, 3장 팔레트
## 범위
- **새 라이브러리 필요 없음(SPEC 2장 범위 안)**: WPF 창으로 직접 구현한다. WPF-UI의 Snackbar/Toast나 H.NotifyIcon 풍선은 쓰지 않는다(클릭 처리·캡처 제외 제어 불가). 새 NuGet 추가가 필요하다고 판단하면 구현 전에 보고서에 이유를 적고 진행자에게 확인을 요청한다
- `ToastWindow : OverlayWindowBase`(캡처 제외·NOACTIVATE·TOOLWINDOW 유지. 새 창이 기반 클래스를 우회하면 반려). 포커스를 훔치지 않는다
- 종류: 성공(`Success`) / 경고(`Warning`) / 오류(`Error`). 제목 + 본문 한두 줄 + 선택적 클릭 동작(`Action`)
- 위치: 커서(또는 주 모니터) 작업 영역의 우하단, 여러 개가 동시에 뜨면 위로 쌓는다. 몇 초 뒤 자동으로 사라진다(표시 시간은 코드 상수 5초, 마우스를 올리면 유지는 선택 사항)
- 스타일: 3장 라이트 팔레트(흰 카드, 테두리 `#E5E8EB`, 본문 `#191F28`, 보조 `#6B7684`, 강조 `#2F7CF6`, 경고 `#FF7A85` 계열), 모서리 12px
- 서비스 인터페이스 `IToastService`(Show(kind, title, message, onClick)). 앱 어디서든 호출 가능하고 UI 스레드로 마샬링한다
- Core에 둘 수 있는 로직(쌓기 위치 계산, 본문 줄임 규칙 등)은 Core로 빼 테스트한다
## 범위 밖
- 스크린샷 연결(task-04), 단축키 실패 알림 교체(task-05), 변환 진행 토스트(세션 5)
## 완료 기준
1. [정적] `ToastWindow`가 `OverlayWindowBase`를 상속하고 캡처 제외가 적용된다 (F-06-1) (파일:줄)
2. [정적] 포커스를 가져가지 않고(NOACTIVATE) 작업표시줄/Alt+Tab에 나타나지 않는다 (F-06-2)
3. [자동] 쌓기 위치 계산(Core): 작업 영역 (0, 0, 1920, 1040), 토스트 360×80, 여백 16, 간격 8일 때 0번째 토스트 위치는 (1544, 944), 1번째는 (1544, 856) (우하단 기준, 위로 쌓임). 작업 영역이 음수 좌표여도 올바르다
4. [정적] 클릭 동작 콜백이 토스트 클릭 시 호출되고 이후 토스트가 닫힌다
5. [정적] 새 NuGet 패키지가 추가되지 않았다(csproj diff)
6. [CI] windows-latest build/test 성공, 새 경고 없음
7. [수동] 토스트가 우하단에 뜨고 몇 초 후 사라지며, 클릭하면 연결 동작이 실행된다(task-04 이후 Windows 확인)
## 검증 방법
qa가 코드 읽기 + 맥 build/test + CI 확인. csproj diff로 패키지 추가 여부 확인.
